# Python Release Ops

## Workflow

1. Define release scope and deployment strategy.
2. Prepare environment and secret configuration checklist.
3. Define migration and backward-compatibility plan.
4. Define observability baseline: logs, metrics, alerts.
5. Define rollback and incident response steps.
6. Define post-release verification and handoff tasks.

## Output Template

- Release Scope
- Pre-Release Checklist
- Deployment Plan
- Migration Plan
- Observability Plan
- Rollback Plan
- Post-Release Verification

## Quality Bar

- Deployment steps must be deterministic and reversible.
- Rollback criteria must be explicit and measurable.
- Post-release checks must include user-impact signals.
